# GreenRoute

**Қозғалыс түрлерін салыстыру** — жаяу жүру, велосипед және қоғамдық көлік бағыттарын
**уақыт** пен **шартты экологиялық әсер** бойынша салыстыратын мобильді қосымша.
Интерфейс қазақша және орысша, жарық және **қараңғы тақырып** бар (жоғарғы оң жақтағы ауыстырғыштар).

> Қазір — **дизайн-прототип**: барлық деректер `src/data.js` ішінде (мок), бэкенд жоқ.
> Кейін React Native/Capacitor арқылы APK етіп жинауға дайындалған.

## Не бар

| Экран | Мазмұны |
| --- | --- |
| **Бағыт** | Қайдан/қайда, ауыстыру батырмасы, схемалық карта, сүзгілер, уақыт/CO₂/құны бойынша сұрыптау, 7 бағыт нұсқасы |
| **Салыстыру** | 2–4 нұсқаны CO₂ және уақыт бойынша салыстыру + **ашық коэффициенттер кестесі** (мәндерді өзгертсең — бүкіл есеп қайта шығады) |
| **Мақсаттар** | Күнделікті CO₂ шегі, апта динамикасы, күнделікті серия, жеке мақсаттар, жетістіктер |
| **Команда** | Бірлескен CO₂ мақсаты, экологиялық тапсырмалар (сыйақысымен), көшбасшылар тақтасы, шақыру коды |

### Детальдар — «?» батырмасында

Экранда тек негізгі сандар қалады: формула, коэффициенттің негіздемесі, есеп жолдары,
карта белгілері, шек пен команда үлесінің есебі — бәрі кішкентай **«?»** батырмасын басқанда
төменнен шығатын парақта (bottom sheet) ашылады (`src/components/Info.jsx`).

### Есеп ашық

```
CO₂  = қашықтық (км) × коэффициент (г CO₂/км)
Үнем = қашықтық × (көлік коэф. − түр коэф.)
```

Бастапқы коэффициенттер (г CO₂/км): жаяу 0, вело 0, самокат 14, автобус 68, троллейбус 40,
метро 28, электромобиль 105, жеңіл көлік 170, такси 170.

Негіздеме: EEA (2023) — жеңіл көлік пен автобустың орташа жолаушы-км көрсеткіші;
IEA / ҚР электр желісінің шартты коэффициенті **0,70 кг CO₂/кВт·сағ**.
Коэффициенттер **шартты**: тек тікелей пайдалану шығарындылары есептеледі, көлік өндірісі,
жанармай өндіру және инфрақұрылым қосылмаған. Пайдаланушы мәнді қолмен өзгерте алады.

## Іске қосу

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ ішіне жинайды
npm run preview  # жиналған нұсқаны тексереді
```

Терең сілтемелер (демо/скриншот үшін): `/?tab=route|compare|goals|team&lang=kk|ru&theme=light|dark`.
Тақырып таңдауы `localStorage`-те сақталады, ал бірінші ашылуда жүйелік баптау алынады.

## APK жинау (Android)

```bash
npm run apk          # = bash scripts/build-apk.sh
```

Нәтиже: жоба түбірінде **`GreenRoute-debug.apk`** (~3,9 МБ). Телефонға көшіріп,
«Белгісіз көздерден орнатуға рұқсат» беріп орнатыңыз.
`appId = kz.greenroute.app`, `minSdk 23`, `targetSdk 35`, debug кілтімен қол қойылған.

**Неге скрипт керек:** жоба жолында кирилл әріптері бар (`Рабочий стол`), ал Android
Gradle плагині (aapt2, javac) ондай жолдармен Windows-та жұмыс істемейді —
`Синтаксическая ошибка в имени файла`. Сондықтан скрипт жобаны ASCII жолға
(`C:\gr-build`) көшіріп, сол жерде жинайды да, дайын APK-ны қайтарады.

Алдын ала орнатылған болуы керек: **JDK 21** (`C:\Users\nurzh\jdk-21.0.12.1+1`),
**Android SDK** (`C:\Users\nurzh\Android\Sdk`, platform-tools + platforms;android-35 +
build-tools;35.0.0). Жолдарды `JAVA_HOME_WIN` / `ANDROID_HOME_WIN` айнымалыларымен
немесе `GR_BUILD_DIR` арқылы өзгертуге болады.

## Келесі қадамдар

1. **Бэкенд** (FastAPI): бағыттар, коэффициенттер, команда/пайдаланушы, статистика.
2. **Нақты карта**: Leaflet + OSM тайлдары (қазір схемалық SVG — офлайн жұмыс істейді).
3. **Геолокация**: `navigator.geolocation` арқылы «Қайдан» нүктесін автоматты қою.
4. **Қол қойылған release APK**: keystore жасап, `assembleRelease` (Play дүкені үшін).

Тек қазақша нұсқасы ғана керек болса — `src/App.jsx` ішіндегі тіл ауыстырғышын (`lang-switch`
блоктарын) өшіріп, әдепкі `lang` мәнін `'kk'` етіп қалдыру жеткілікті.
